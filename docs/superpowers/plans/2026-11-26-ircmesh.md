# ircmesh Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `ircmesh`, a second binary that serves a Meshtastic node as an IRC server (a bouncer) through the meshtastik daemon.

**Architecture:** Part A prepares the shared code. The daemon echoes text sent by one client to its other clients, `device.Client` can send text under a caller-chosen packet id, and target resolution plus daemon dialling move from `internal/cli` into `internal/nodeconn`. Part B builds pure, separately tested pieces: IRC wire format (`internal/irc`), plus nicks, channels, membership, text rendering and replay (`internal/ircmesh`). Part C is the server in `internal/ircmesh`. State lives behind one mutex, and each IRC client has a reader goroutine and a writer goroutine with a bounded queue. The mesh is consumed through `device.Client.Listen` under a supervisor that reopens it. Part D is `cmd/ircmesh` (flags, TLS, hosting the daemon in-process) and the release.

**Tech Stack:** Go 1.27, standard library `net`/`crypto/tls` (no IRC library), the official Buf-generated Meshtastic protobufs, `internal/fakedevice` for tests.

**Spec:** `docs/superpowers/specs/2026-11-26-ircmesh-design.md`

There are four parts: A (Tasks 1–3), B (4–8), C (9–13) and D (14–15). Run `make check` at the end of every task. It must pass before the commit.

## Global Constraints

- Binary `ircmesh`, built from `cmd/ircmesh`. Version set with `-X main.version=…`, default `"dev"`.
- `ircmesh` never imports `internal/cli` and never execs `meshtastik`.
- Listen default `127.0.0.1:6667`. A non-loopback address without a password is refused at startup.
- Password comes from `--password-file` (wins) or `MESHTASTIK_IRC_PASSWORD`. Surrounding whitespace is trimmed, and an empty result counts as no password.
- `--active` default `24h`.
- ISUPPORT: `CHANTYPES=# NICKLEN=16 CHANNELLEN=32 CASEMAPPING=ascii NETWORK=mesh`.
- The only capability offered is `server-time`, using tag format `@time=2006-01-02T15:04:05.000Z` (UTC).
- Hostmask `<nick>!<8 lowercase hex of node num>@mesh`. Realname is the long name. Server name is `ircmesh`.
- Mesh text limit is 200 bytes per packet, at most 3 packets per IRC message, with at least 2 s between packets (`Config.SendInterval`).
- DM ack wait is 30 s (`Config.DMTimeout`).
- Replay buffers hold at most 100 entries per channel index and per DM peer. The recent-message index for reactions and replies holds 1000 entries. Quotes are 30 runes plus `…` when truncated.
- Membership file is `<os.UserConfigDir()>/ircmesh/members-<8 hex of own node num>.json`, directory mode 0700, file mode 0600.
- An IRC client's write queue holds 4096 lines. Overflow disconnects that client with `ERROR :SendQ exceeded`.
- Registration timeout is 60 s. The server sends `PING` after 90 s of client silence and disconnects after a further 90 s (`ERROR :Ping timeout`).
- Node state refresh runs every 10 min and after a `rebooted` message.
- Mesh reopen backoff runs from 1 s, doubling to 60 s, forever. The first open failing is fatal.
- Match the existing code: comment density, lowercase specific error text, table-driven tests where the existing tests use them.

## Review Focus

1. **Mesh text containing `\n`, `\r` or NUL.** It must never inject raw IRC lines. Each non-empty line becomes its own PRIVMSG, and `\r`/NUL are dropped. Test: `TestRenderSplitsLines` (Task 7).
2. **A short name that sanitises to something starting with a digit or `-`** (for example `1c70`). This is not a legal nick. Prefix it with `_` (`_1c70`). Test: `TestBaseNickLeadingDigit` (Task 5).
3. **Packets that say nothing reliable about a channel.** These are undecoded packets, whose `channel` is a hash rather than an index, PKI DMs, and packets not addressed to broadcast. They must not create memberships, so a DM from a stranger doesn't put them in `#Ryfylke`. Test: `TestCountsOnlyDecodedBroadcasts` (Task 6).
4. **Non-UTF-8 bytes from an IRC client** (a Latin-1 client). They are decoded as Latin-1 and sent as valid UTF-8. Invalid UTF-8 from the mesh becomes U+FFFD. Tests: `TestToUTF8Latin1` (Task 4) and `TestRenderSplitsLines` (Task 7).
5. **An IRC client that stops reading** (a laptop asleep with TCP still open). It must not stall other clients or mesh handling. Its queue overflows and it alone is dropped. Test: `TestStalledClientIsDropped` (Task 11).

## Part B — Pure building blocks

### Task 4: IRC wire format

**Files:**
- Create: `internal/irc/irc.go`, `internal/irc/irc_test.go`

**Interfaces:**
- Produces (package `irc`):
  - `type Message struct{ Tags map[string]string; Prefix, Command string; Params []string }`.
  - `func Parse(line string) (Message, error)`. The line has no CRLF. Command is upper-cased. IRCv3 tag values are unescaped. An empty line or one without a command is an error.
  - `func (m Message) String() string`. No CRLF. Tags are sorted and escaped. The last param gets `:` when it's empty, contains a space, or starts with `:`.
  - `func Fold(s string) string`: ASCII case mapping (`A–Z` to `a–z` only).
  - `func StripFormatting(s string) string`. Removes `\x02 \x1d \x1f \x1e \x11 \x16 \x0f`, plus `\x03` followed by up to 2 digits and an optional `,` with up to 2 digits, plus `\x04` followed by up to 6 hex digits and an optional `,` with up to 6 hex digits.
  - `func ParseCTCP(text string) (cmd, arg string, ok bool)` and `func CTCP(cmd, arg string) string` (`\x01CMD arg\x01`; the trailing `\x01` is optional when parsing).
  - `func ToUTF8(s string) string`: returned unchanged if valid UTF-8, otherwise each byte is decoded as Latin-1.

### Task 5: Nicks, channel names and the node directory

**Files:**
- Create: `internal/ircmesh/names.go`, `internal/ircmesh/directory.go`, `internal/ircmesh/names_test.go`, `internal/ircmesh/directory_test.go`

**Interfaces:**
- Consumes: `irc.Fold`.
- Produces (package `ircmesh`, unexported):
  - `const nickLen = 16`.
  - `func baseNick(u *pb.User, num uint32) string`. Takes the first non-empty of: the short name sanitised; the long name with spaces turned into `_`, sanitised and cut to 16; `n` plus the last 4 hex digits of `num`. Sanitising keeps ASCII letters, digits and `[]\`_^{|}-`. A result starting with a digit or `-` gets a `_` prefix. The result is at most 16 bytes.
  - `func channelNames(chs [8]*pb.Channel, lora *pb.Config_LoRaConfig) map[int]string`. Maps enabled indexes (role PRIMARY or SECONDARY) to `#name`. Sanitising keeps ASCII letters, digits and `-_.`. An empty primary name uses `presetName`, and an empty secondary name uses `ch<index>`. When names collide (compared with `Fold`), the lowest index keeps the plain name and the others become `#name-<index>`.
  - `func presetName(lora *pb.Config_LoRaConfig) string`. `LONG_FAST` gives `LongFast` (the enum words title-cased and joined). `UsePreset == false` gives `Custom`.
  - `func channelTopic(ch *pb.Channel, lora *pb.Config_LoRaConfig) string`. Format: `channel <i> · primary|secondary · <preset> · default key|simple key|custom key|no encryption`. PSK length 0 is no encryption. Length 1 with value 1 is the default key. Other length-1 PSKs are a simple key. Anything longer is a custom key.
  - `type directory struct` and `func newDirectory(self uint32) *directory`.
  - `type nickChange struct{ Num uint32; Old, New string }`.
  - `func (d *directory) set(num uint32, u *pb.User) []nickChange`. Returns every nick that changed, which can include a node other than `num` when self takes its base. Nicks are sticky: a node keeps its nick until its names change. On a collision (by `Fold`) with another node, the newcomer gets `<base cut to 11>-<last 4 hex>`, falling back to `-<8 hex>` if that also collides. The self node is never suffixed. Any other node holding self's base yields to self, and that change is reported.
  - `func (d *directory) nick(num uint32) string`. Assigns a fallback nick to unknown nodes.
  - `func (d *directory) lookup(nick string) (uint32, bool)`, compared with `Fold`.
  - `func (d *directory) user(num uint32) *pb.User` and `func (d *directory) mask(num uint32) string` (`nick!%08x@mesh`).

### Task 9: Server core, registration and connection housekeeping

**Files:**
- Create: `internal/ircmesh/server.go`, `internal/ircmesh/client.go`, `internal/ircmesh/harness_test.go`, `internal/ircmesh/server_test.go`

**Interfaces:**
- Consumes: Tasks 4–8.
- Produces:
  - `type Mesh interface { State() *device.State; Listen(ctx context.Context, fn func(*pb.FromRadio) error) error; SendTextID(ctx context.Context, id uint32, text string, to, channel uint32, waitAck bool) error; Refresh(ctx context.Context) error; Close() error }`. `*device.Client` satisfies it.
  - `type Config struct { Version string; Open func(ctx context.Context, opts device.Options) (Mesh, error); Password string; Active time.Duration; StateDir string; Log io.Writer; Now func() time.Time; SendInterval, DMTimeout time.Duration }`. ### Task 12: IRC to mesh

**Files:**
- Create: `internal/ircmesh/outbound.go`, `internal/ircmesh/outbound_test.go`

**Interfaces:**
- Consumes: `splitText`, `irc.StripFormatting`, `irc.ParseCTCP`, `irc.ToUTF8`, `device.NewPacketID`, `Mesh.SendTextID`.
- Produces: the `PRIVMSG` handler and one sender goroutine per open mesh, fed by a FIFO channel of jobs.
  - **Target:** `#c` sends to that channel index with `device.Broadcast`. A nick resolved with `directory.lookup` is a DM on channel 0. An unknown target gives `401`/`403`, and a DM to self gives a `NOTICE`.
  - **Text cleanup:** `ToUTF8`, then `StripFormatting`. CTCP `ACTION x` becomes `* <self nick> x`. CTCP `VERSION` is answered with `NOTICE <client> :\x01VERSION ircmesh <version>\x01`. Other CTCP is dropped, and nothing is sent to the mesh for any CTCP except ACTION.
  - **Split:** `splitText(text, 200, 3)`. `errTooLong` gives `NOTICE <self> :message too long for the mesh (<n> bytes, at most 3 packets of 200) — not sent`.
  - **Sending:** at least `SendInterval` between packets. A broadcast calls `SendTextID(…, false)` in the sender. A DM starts `SendTextID(…, true)` in its own goroutine with a `DMTimeout` context. On error the client gets `NOTICE <self> :message to <nick> not delivered (<err>): "<quote>"`. A channel send error gives `NOTICE #c :not sent: <err>`.
  - **Echo:** each sent part is recorded in `recent` under its id and echoed as `:<self mask> PRIVMSG <target> :<part>` to every *other* registered client (not the sender).
  - **`NOTICE`:** from IRC clients it is never sent to the mesh and gets no reply.

### Task 13: Link supervision and node config changes

**Files:**
- Create: `internal/ircmesh/link.go`, `internal/ircmesh/link_test.go`

**Interfaces:**
- Consumes: `Config.Open`, `device.Options.OnReconnect`, `OnReconnected` and `OnMessage`.
- Produces:
  - **Supervisor loop:** open the mesh, then `Listen`. `OnReconnect` marks the link down. Only on the first call of an outage, every client gets `NOTICE <nick> :mesh link down (<cause>); reconnecting`. `OnReconnected` marks it up and sends `NOTICE <nick> :mesh link back up`. If `Listen` returns an error, the supervisor marks the link down, closes the mesh and reopens it with backoff (1 s doubling to 60 s), giving the same notices.
  - **While down:** `PRIVMSG` gets `NOTICE <self> :mesh link is down; message not sent`. Jobs still queued in the sender are dropped with the same NOTICE. Membership and replay stay as they are.
  - **Refresh:** every 10 min, and when `OnMessage` sees `rebooted` (signalled non-blockingly), call `Refresh`. Then `func (s *Server) syncState(st *device.State)`:
    - Re-run `directory.set` for every node, sending NICK changes.
    - Recompute `channelNames`. An index that is gone or renamed gets `PART <old> :channel removed on node` to clients, plus `membership.dropChannel` and `replay.dropChannel` for a removed index. A new or renamed index gets the join burst.
    - A self nick change goes to clients as `:<old self mask> NICK :<new>`.
